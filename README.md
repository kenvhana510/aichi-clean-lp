# AICHI CLEAN｜ハウスクリーニング 集客LP（Web制作ポートフォリオ 2作目）

架空のハウスクリーニング会社「AICHI CLEAN」の集客用ランディングページ。
Web制作案件獲得のためのポートフォリオとして、**問い合わせ獲得（無料見積もり依頼）を目的としたLP**を、
企画・構成設計・コピーライティング・デザイン・レスポンシブ実装まで一貫して制作しています。

> **本サイトはポートフォリオ用に制作した架空サイトです。**
> 掲載している企業名・サービス・料金・口コミ・実績・対応エリア等はすべて架空の情報です。
> 掲載画像にはAI生成画像を含みます。実在する企業・サービスとは一切関係ありません。

**リポジトリ**：https://github.com/kenvhana510/aichi-clean-lp

## 1. 制作目的

ポートフォリオ1作目（製造業の採用LP）とは**業種・目的・デザインを明確に変え**、
「見た目を作れる」だけでなく **「目的に合わせてコンバージョン導線を設計できる」** ことを示すために制作しています。

| | 1作目 | 2作目（本作） |
|---|---|---|
| 業種 | 製造業・人材採用 | 地域サービス業・ハウスクリーニング |
| 目的 | 求人応募の獲得 | 問い合わせ・無料見積もりの獲得 |
| 主読者 | 未経験の求職者 | 家事の時間が取れない一般家庭 |
| デザイン | ネイビー×ブルー／工場写真の全面ビジュアル | 白ベース×ネイビー／清潔感・余白重視 |
| 訴求の軸 | 不安の解消 → 応募 | 悩みの提示 → 解決策 → 料金の明示 → 問い合わせ |

---

## 2. ターゲット

- 共働き世帯／子育て世帯（掃除に時間を使えない）
- 高齢者世帯（自分では届かない場所の掃除が難しい）
- エアコン・水回りをプロに依頼したい人

**インサイト**：「頼みたい気持ちはあるが、料金が不透明で踏み出せない」
→ 料金を早い段階で明示し、追加料金の考え方まで説明することで問い合わせのハードルを下げる構成にしています。

| # | セクション | 役割 |

## 4. 使用技術

- HTML5 / CSS3 / Vanilla JavaScript
- **ビルドツール・フレームワーク不使用**（納品・引き継ぎが容易な構成）
- 外部依存は Google Fonts（Zen Kaku Gothic New）のみ
- 画像は WebP を優先配信し、非対応環境へは JPEG をフォールバック（`<picture>` 要素）

---

## 5. 実装機能

- ハンバーガーメニュー（1024px未満）
- スムーススクロール
- FAQアコーディオン
- 問い合わせフォーム（HTML5バリデーション＋疑似送信。**実送信は行いません**）
- スマホ固定CTA（画面下部に常時表示）
- スクロール連動の軽いフェードイン（`prefers-reduced-motion` 対応）

| Mobile | 375px |
| Tablet | 768px |

---

## 7. SEO・アクセシビリティ

- `title` / `meta description` / `viewport` / OGP（`og:image` 1200×630・`twitter:card` 含む）
- `noindex, nofollow`：架空サービスのため、実在のサービスとして検索結果に出ないよう設定（本番移行時は削除）
- 意味的なHTML（`section` / `article` / `dl` 等）、`h1`は1つのみ
- 画像 `alt`、フォーム `label` の関連付け、`button` 要素の適正使用
- フォーカス表示（`:focus-visible`）、キーボード操作対応
- 本文と背景のコントラスト確保

## 10. 使用画像（全11枚）

すべてAI生成画像。元画像は `images/_source/` に保管（`.gitignore` で公開対象外）。
JPEG＋WebPの2形式で書き出し、`<picture>` でWebPを優先配信しています。

| ファイル | 用途 | サイズ |
|---|---|---|
| `hero-main` | HERO右カラム | 1200×900 |
| `service-aircon` / `-kitchen` / `-bath` | サービス一覧（3点） | 800×600 |
| `ba-kitchen-before` / `-after` | BEFORE/AFTER キッチン | 800×600 |
| `ba-bath-before` / `-after` | BEFORE/AFTER 浴室 | 800×600 |
| `ba-aircon-before` / `-after` | BEFORE/AFTER エアコン | 800×600 |
| `final-cta-bg` | 最終CTA背景 | 1600×800 |
| `ogp.jpg` | OGP（SNS共有時のサムネイル） | 1200×630 |

**配信容量：WebP合計 434KB**（JPEG合計 806KB）。

- BEFORE/AFTER は、BEFORE画像を入力として編集で AFTER を作成しており、
  **3組とも同一アングル・同一設備で、差分は汚れの有無のみ**です。
- サービス一覧のうち「トイレ／洗面所／お家まるごと」の3カードは、
  画像を持たない**テキスト主体カード**として意図的にデザインしています（`.service-card--compact`）。
